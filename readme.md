# Permix
An extension to easily moniter things that browser hide.

![screenshot of dashboard](https://cdn.hackclub.com/019fce5f-f391-7c0d-8d81-f17ca27a928a/image.png)

## Features
While I initially wanted to allow you to modify permissions such as camera, microphoe etc. I learned that extensions couldn't manage that because of browser restrictions.

So currently, the below are the only abilities.
- Clear browser cache
- Clear website cookies

## Tech Stack
- Frontend
  - Vanilla HTML, CSS, JS
- Backend
  - Chrome extension packing

## Extension Installation:

### FIREFOX:
Simply install from the Firefox Addon store [here](https://addons.mozilla.org/addon/permix/)

### OTHER BROWSERS:
1. Download and extract the latest extension from [here](https://github.com/Jack-Jacobson/Permix) (download the repo as a zip file, then right click -> extract)
2. In your browser, navigate to [chrome://extensions](chrome://extensions)
3. Enable developer mode in the top right corner
4. Click load unpacked and navigate to the folder you extractedand click select.
